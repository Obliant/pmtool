Instruções de uso

Guia completo — Project Track · Portfólio de Projetos

🚀 Como começar um novo projeto

1. Criar o projeto — Na tela inicial clique em + Novo projeto, dê um nome e confirme.
2. Preencher Configurações — Informe nome, cliente, gerente do projeto e datas de início e término.
3. Importar o cronograma — No MS Project: Arquivo → Salvar Como → CSV (separador ponto-e-vírgula). Depois vá em Importar e selecione o arquivo.
4. Importar o forecast de horas — Preencha o template de forecast, exporte como CSV e importe em Horas → Importar forecast.
5. Pronto! — O Dashboard já mostra os indicadores. Agora é só atualizar conforme o projeto avança.

📅 Rotina de atualização

Tarefas: 🔘 Não iniciado → 0% automático · 🟣 Em progresso → % calculado pelas datas · 🟢 Concluído → 100% automático · 🔴 Em atraso → congela o % e sinaliza vermelho

Horas: vá em Horas, selecione o mês e informe as horas realizadas de cada consultor. O dashboard atualiza automaticamente.

Marcos críticos: em Tarefas, clique na bandeira 🚩 para marcar uma tarefa como marco crítico.

📊 Entenda os indicadores do Dashboard

SPI — % realizado ÷ % planejado. 🟢 ≥1.00 no ritmo · 🟡 0.85–1.00 leve atraso · 🔴 <0.85 atraso crítico

CPI — % entregue ÷ % de horas gastas. 🟢 ≥1.00 eficiente · 🟡 0.85–1.00 leve estouro · 🔴 <0.85 estouro crítico

EAC — projeção de horas/custo total mantido o ritmo atual.
