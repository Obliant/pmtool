Instruções de uso

Guia completo — Project Track · Portfólio de Projetos
🚀 Como começar um novo projeto
1
Criar o projeto
Na tela inicial clique em + Novo projeto, dê um nome e confirme.
2
Preencher Configurações
Informe nome, cliente, gerente do projeto e datas de início e término.
3
Importar o cronograma
No MS Project: Arquivo → Salvar Como → CSV (separador ponto-e-vírgula). Depois vá em Importar e selecione o arquivo.
4
Importar o forecast de horas
Preencha o template de forecast (botão abaixo), exporte como CSV e importe em Horas → Importar forecast.
5
Pronto!
O Dashboard já mostra os indicadores. Agora é só atualizar conforme o projeto avança.
📅 Rotina de atualização
Atualização das tarefas
Vá em Tarefas e atualize o status de cada tarefa:
🔘 Não iniciado → 0% automático
🟣 Em progresso → % calculado pelas datas
🟢 Concluído → 100% automático
🔴 Em atraso → congela o % e sinaliza vermelho
Lançamento de horas (mensal)
Vá em Horas, selecione o mês e informe as horas realizadas de cada consultor.

O dashboard atualiza automaticamente o burn chart e o saldo do pacote.
🚩 Marcos críticos

Na aba Tarefas, cada linha tem um ícone de bandeira 🚩. Clique nele para marcar a tarefa como marco crítico — ela aparece automaticamente na aba Marcos com a data planejada e o status sincronizado.
Ideal para aprovações (MIT030, MIT041, etc.) e entregas formais ao cliente.

💾 Dados e projetos

Os dados ficam salvos no navegador — não se perdem ao fechar. Cada projeto tem seus dados isolados.
Para trocar de projeto, clique no nome do projeto na barra lateral.
Para exportar um relatório snapshot, clique em Exportar relatório no Dashboard.
Atenção: limpar o cache do navegador apaga os dados. Exporte o relatório regularmente como backup.

📊 Entenda os indicadores do Dashboard
Como ler os semáforos:🟢 bom🟡 atenção🔴 crítico
⏱️ Prazo
% Realizado × % Planejado
Realizado = quanto do projeto já foi concluído hoje (ponderado pela duração das tarefas). Planejado = quanto deveria estar pronto até hoje. Realizado abaixo do planejado indica atraso.
SPI — Índice de Desempenho de Prazo
% realizado ÷ % planejado. Diz se o projeto está no ritmo.
🟢 ≥ 1,00 no ritmo · 🟡 0,85–1,00 leve atraso · 🔴 < 0,85 atraso crítico
Dias restantes · Previsão · Desvio
Dias até a data prevista; data projetada de conclusão pelo ritmo atual (SPI); e o desvio em dias entre as duas.
💰 Esforço & Custo
CPI — Índice de Custo/Esforço
% entregue ÷ % de horas gastas. Diz se as horas estão sendo usadas de forma eficiente.
🟢 ≥ 1,00 eficiente · 🟡 0,85–1,00 leve estouro · 🔴 < 0,85 estouro crítico
EAC — Projeção no término
Estima as horas / o custo totais no fim, mantido o ritmo atual. Comparado ao contratado, antecipa estouro.
Saldo de horas / custo
Contratado − realizado. Negativo = já estourou o previsto.
🚦 Saúde do projeto
Semáforo geral 🟢🟡🔴
Combina prazo (SPI), esforço (CPI), riscos e marcos, e assume a pior dimensão: se qualquer uma estiver crítica, o projeto aparece crítico. É a leitura rápida de "como o projeto está hoje".
🎯 Marcos & ⚠️ Riscos
Marcos
% de marcos atingidos, quantos estão atrasados e qual é o próximo marco a vencer.
Riscos
Riscos abertos na carteira e os de alta criticidade — alta probabilidade E alto impacto, que são os que mais ameaçam.
